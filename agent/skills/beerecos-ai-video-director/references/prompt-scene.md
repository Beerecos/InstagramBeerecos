# Gabarit de prompt de scène

```
[Format] Vertical 9:16, 1080x1920, {durée}s.
[Plan] {gros plan|plan moyen|plan large}, {mouvement caméra lent : travelling avant, panoramique…}.
[Sujet] {description précise, identique d'une scène à l'autre pour la continuité}.
[Décor] {lieu crédible : bureau de PME, atelier, salle de réunion lumineuse…}.
[Lumière/couleur] {naturelle douce, palette de la marque}.
[Action] {une seule action lisible}.
[Audio] {aucun | ambiance | voix native si le moteur le permet}.
[Exclusions] pas de texte, pas de logo, pas de filigrane, pas de visages déformés.
```
