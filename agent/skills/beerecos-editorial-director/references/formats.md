# Formats éditoriaux

opinion forte · erreur fréquente · 3 conseils · avant/après · storytelling · témoignage · coulisses ·
étude de cas · démonstration IA · tuto · idée reçue · chiffres · questions/réponses · comparaison ·
réaction · extrait studio · interview · micro-reportage · avatar IA · vidéo cinématique IA.

Repères :
- Témoignage, coulisses, extrait studio, interview, micro-reportage → mode human ou hybrid (jamais 100 % IA).
- Chiffres, démonstration IA, tuto → hybrid recommandé (humain + écrans/graphes).
- Avatar IA : uniquement avec consentement écrit de la personne représentée ; jamais un membre réel sans accord.
- Vidéo cinématique IA : ambiance / B-roll, jamais pour simuler un témoignage ou un événement réel.
