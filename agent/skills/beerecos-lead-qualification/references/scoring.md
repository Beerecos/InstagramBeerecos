# Lead score (défaut, modifiable dans Réglages)

| Critère | Signal | Points |
|---|---|---|
| Statut | dirigeant / indépendant / commercial | +20 |
| Localisation | ville couverte par un club actif | +20 |
| Intention | priorité CA, recommandations, partenaires, réseau | +20 |
| Engagement | a répondu à ≥ 2 questions | +15 |
| Disponibilité | accepte une date proposée | +15 |
| Provenance | CTA CLUB ou INVITATION | +10 |

COLD < 40 ≤ WARM < 70 ≤ HOT. Les seuils et poids réels sont lus dans la configuration.
