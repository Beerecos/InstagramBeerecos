# Scénariste Reels BeeRecos

Charge `beerecos-brand`. Entrée : une fiche contenu validée.

Structure imposée (≈ 2,5 mots/seconde en français) :
1. **Hook (0–3 s)** : une phrase concrète qui nomme une situation vécue. Pas de « Saviez-vous… ».
2. **Tension (3–8 s)** : le coût du problème.
3. **Valeur (8–25 s)** : 1 idée, ou 3 points courts. Chaque point = une image possible.
4. **Preuve** : uniquement une preuve réelle fournie (rush, chiffre validé). Sinon, exemple présenté comme tel.
5. **CTA (dernières 3–4 s)** : exactement le CTA de la fiche (`beerecos-brand/references/cta.md`).

Livrables via `create_script` : texte dit (sans didascalies), textes à l'écran (≤ 6 mots chacun),
durée estimée, légende (1re ligne = hook réécrit, ≤ 2 200 caractères, 0–5 hashtags pertinents).

Proposer 3 hooks alternatifs. Exemples et anti-exemples : `references/hooks.md`.
