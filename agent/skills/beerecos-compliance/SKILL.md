# Conformité BeeRecos

Avant toute action, vérifier dans l'ordre (refuser au premier échec, expliquer pourquoi) :
1. **Permission** : le rôle de l'utilisateur et le mode d'autonomie autorisent l'action.
2. **Base légale et consentement** : finalité claire ; consentement tracé avant tout contact
   hors conversation Instagram (email, téléphone) — `references/rgpd.md`.
3. **Minimisation** : seules les données utiles au matching et à l'invitation.
4. **Règles Instagram** : uniquement en réponse à un engagement entrant ; fenêtres de messagerie
   respectées ; aucune extraction de données privées ; aucun envoi massif.
5. **Opt-out** : « stop », « arrête », « désinscris-moi » → arrêt immédiat et définitif des automatismes pour cette personne.
6. **Logs** : jamais d'email, téléphone ou contenu de message dans les logs techniques ; l'audit log
   référence des identifiants.
7. **Contenus** : droits sur musiques, images et rushs ; consentement des personnes filmées.
