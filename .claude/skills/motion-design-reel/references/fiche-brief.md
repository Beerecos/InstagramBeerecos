# Fiche brief

À remplir avant chaque vidéo (copier dans `briefs/AAAA-MM-JJ-<sujet>.md`), puis la donner
à Claude avec le rush. Si l'utilisateur ne la fournit pas, poser ces questions en une fois.

```markdown
# Brief — <titre>

- **Ma vidéo parle de :**
- **L'émotion à faire ressentir :**
- **Mon style (couleurs, polices, mouvement) :** voir STYLE.md / ou préciser
- **Moment fort 1 (le mot + l'effet) :**
- **Moment fort 2 (le mot + l'effet) :**
- **Moment fort 3 (le mot + l'effet) :**
- **Format et durée :** 1080×1920, 60 i/s, ~20 s
- **Ce que je ne veux surtout pas :**
- **Rush :** rush/<fichier>.mp4
```

## Ta première vidéo en 45 minutes

| Temps | Étape | Ce qu'on fait |
|---|---|---|
| 0:00 | Installer | `scripts/setup-check.sh` ; prêt quand Hyperframes répond |
| 0:05 | Filmer | 20 s face caméra, vertical, une seule idée. 3 prises, garder la meilleure |
| 0:15 | Briefer | Remplir la fiche, la donner avec le rush |
| 0:20 | Storyboard | Claude propose un plan ; garder 3 moments forts, barrer le reste |
| 0:25 | Construire | Claude construit ; regarder la preview une fois en entier |
| 0:35 | Retoucher | 3 retouches maximum : taille, timing, style |
| 0:40 | Publier | Export, check des zones cachées, publication |

## Le défi 7 jours

Une vidéo de 15 s par jour, un effet à la fois. Au bout d'une semaine : 7 contenus publiés
et un style qui appartient au compte.

| Jour | Effet à travailler |
|---|---|
| J1 | Titre d'accroche |
| J2 | Sous-titres dynamiques |
| J3 | Texte derrière toi |
| J4 | Widget réaliste |
| J5 | Chiffre animé |
| J6 | Zoom + transition |
| J7 | Tout combiné, avec la phrase de style |
